# Quick Task 260620-q01: Fix navbar scroll navigation

**Date:** 2026-06-20
**Slug:** navbar-scroll-fix

## Problem

Clicking nav links (Über mich, Skills, Portfolio, Kontakt) does not scroll correctly. Native `href="#id"` anchor links combined with the DC Runtime/React rendering layer do not reliably apply `scroll-margin-top` for the fixed nav offset.

## Fix

Add `setupNavScroll()` method to the Component class that:
1. Intercepts clicks on all `a[href^="#"]` links
2. Calls `e.preventDefault()` to suppress native anchor behavior
3. Manually smooth-scrolls to the target section with the correct nav height offset

- [x] Add `setupNavScroll()` method to `Portfolio.dc.html` Component class
- [x] Call `this.setupNavScroll()` from `componentDidMount()`
