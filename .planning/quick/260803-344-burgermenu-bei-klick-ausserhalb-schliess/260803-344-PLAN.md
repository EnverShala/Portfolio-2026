  <files>Portfolio.dc.html</files>
  <action>
Add a `setupOutsideClick()` method to the `Component` class, placed immediately after the existing `setupNavScroll()` method (which ends at line 864) and before `setupProgress()`.

The method assigns a handler to `this._onOutside` and registers it on `document` for the **`pointerdown`** event. Do NOT use `click`: iOS Safari does not reliably deliver bubbled `click` events from taps on non-interactive elements, which would leave the menu stuck open on exactly the devices this fix targets. `pointerdown` fires for mouse, touch, and pen on all supported browsers.

Handler logic, in order:
1. Read `const menu = document.getElementById('nav-mobile-menu')`. If it is missing, or `menu.style.display === 'none'`, return immediately — the menu is closed, nothing to do. Use this DOM check rather than `this.state.menuOpen`; it mirrors the guard already used in `setupNavScroll` (line 850) and stays correct even if a render cycle lags behind.
2. Read `const nav = document.getElementById('main-nav')`. If `nav && nav.contains(e.target)` is true, return — the tap landed on the burger button or inside the menu panel itself. This guard is what prevents the close-then-reopen flicker: `pointerdown` fires before the burger's `click`, so without it the menu would close and `toggleMenu` would instantly reopen it.
3. Otherwise call `this.closeMenu()`. Reuse the existing method (lines 594–600) — do not re-implement the display/class toggling.

Register with `document.addEventListener('pointerdown', this._onOutside)`.

Then wire the lifecycle:
- In `componentDidMount()` (line 708), add `this.setupOutsideClick();` directly after the existing `this.setupNavScroll();` line.
- In `componentWillUnmount()` (line 721), add `if (this._onOutside) document.removeEventListener('pointerdown', this._onOutside);` alongside the existing removal lines, following the exact `if (this._onXxx) ...removeEventListener...` shape already used for `_onScroll` and `_onOver`.

Do not touch `toggleMenu`, `closeMenu`, the nav markup, or the `<style>` block. No Escape-key handling and no scroll/resize auto-close — out of scope for this task.
